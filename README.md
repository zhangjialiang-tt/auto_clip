# Anti-Lock (防锁屏工具)

一个轻量级的 Windows 防锁屏工具，通过模拟微小的鼠标动作来保持系统活跃。

## 🎯 功能特点

- **轻量级**: 基于 Python `tkinter` 和原生 Windows API，无需庞大的第三方库。
- **无感干扰**: 使用“微抖动”策略（鼠标右移 1 像素立即左移 1 像素），肉眼几乎无法察觉，不影响正常工作。
- **智能监控**: 实时显示当前系统空闲时间，仅在超过设定阈值时触发。
- **自动复位**: 检测到用户真实的鼠标/键盘操作后，自动重置计时器。

## 🛠️ 技术栈

- **语言**: Python 3.x
- **GUI**: tkinter (Python 内置)
- **核心逻辑**: ctypes (调用 user32.dll/kernel32.dll)

## 🚀 快速开始

### 1. 运行源码

无需额外安装任何库（Python 标准库即可）：

```bash
# 进入 src 目录运行
cd src
python main.py
```

### 2. 打包为 EXE

如果您希望生成独立的 `.exe` 文件：

1. 安装 PyInstaller:
   ```bash
   pip install pyinstaller
   ```

2. 执行打包命令 (在项目根目录):
   ```bash
   pyinstaller --noconsole --onefile --clean --name="AntiLock" src/main.py
   ```

3. 在 `dist` 目录下找到 `AntiLock.exe` 即可运行。

## ⚙️ 使用说明

1. 打开软件，设置 **触发阈值**（默认 60 秒）。
2. 点击 **启动监控**。
3. 此时如果不操作电脑，空闲时间会累积。
4. 当空闲时间达到阈值时，软件会自动执行一次微抖动，重置系统空闲计时器，防止屏幕锁定或进入睡眠。

## ⚠️ 注意事项

- 本工具仅用于防止系统因长时间无操作而自动锁屏/睡眠。
- 请勿用于绕过公司安全合规检查。
